                    1. 
              
                      The desk
                      
              
                      Under the picture, top to bottom: the tempo row (beat light, BPM, the slider, Auto: Read Live, Tap/Phase, x2, /2, Nudge +, and Nudge -), then Loop, Bars, the position readout, Master Speed, X-fade, the transition style, and Output Brightness. Then the timeline. Then the scene name, Save Scene, the hit pads, and Code, Screen, and Brand. Then the scene grid. Then layers A, B, and C.
                      
              
                      Composition is the top-right column, beside the picture. The Inspector is the bottom-right column, beside the layers. The left column is the project.
                      
            
                      2. 
            
                    2. 
              
                      Hello
                      
              
                      Hello holds New Project, Load Project, Save, and Save New. Save writes into the current project file. Save New asks where to put a copy. Both store the scenes, timeline, project media, audio, levels, output, recording settings, and which views are open. In the desktop app, media, audio, and logo files are copied into a folder next to the project.
                      
              
                      Undo and Redo sit in the top bar (Ctrl+Z, Ctrl+Shift+Z or Ctrl+Y). Preferences sets the UI scale, whether the app opens in Live, Perform, or Media Manager, whether it reopens the last project, where new projects are created, the media library folder, the fetched-media folder, and the recordings folder. Open shows that folder on the computer. The View checks show or hide the timeline, Project Media, the Inspector, each layer, and Composition.
                      
            
                      3. 
            
                    3. 
              
                      Media Manager
                      
              
                      Drop a video or image, or click the drop area. Videos are fitted to 1920×1080 and encoded H.264 into the library. Tag a logo Brand asset before it is stored. The gallery is kept across restarts. Select clips, tag them, then Add to Project. Bypass Transcode & Add Directly skips the conversion. Transcoding runs in the desktop app. Drag the bar under the drop area to give the gallery more room.
                      
              
                      Project Media lists only the clips added to this project. Each one is a reference to the library file. Click + to open Media Manager. On a card, A, B, or C assigns that clip. Removing a clip from the project drops it from this show. If a layer is playing it, that layer returns to the test pattern.
                      
            
                      4. 
            
                    4. 
              
                      Audio
                      
              
                      In the Audio fold, Live Hardware picks an input. Local File lists audio already in Media Manager. Drop a track to add it there first; the desktop app stores a lighter copy, then it shows up in the list. The last three played stay underneath. Search Stock Audio finds Wikimedia clips and saves a 44.1 kHz wav. Play starts the file. Loop Audio repeats it. Sync to Master lets the top-bar Play, Pause, and Stop drive it.
                      
              
                      Auto-Gain holds the level. Master Gain and Mute set how hard the sound hits the picture. The meters read KICK, SNARE, NRG, BRK, and DROP.
                      
            
                      5. 
            
                    5. 
              
                      Layers
                      
              
                      A, B, and C sit under the scene grid. Select, or Q, W, and E. The mix menu sets how the layer sits on the one below. The opacity fader brings it in. Mute and Solo cut or isolate it. Sync follows the top-bar transport. A layer set to Lock keeps playing through Play, Pause, and Stop.
                      
            
                      6. 
            
                    6. 
              
                      Looks
                      
              
                      With a layer selected, pick a shader in the Inspector, or press 1–9 for the first nine, from Glitch and Y2K / 2000s through Black Metallic Y2K. On the 3D looks, drag the preview to orbit and scroll to zoom.
                      
            
                      7. 
            
                    7. 
              
                      Inspector
                      
              
                      One layer at a time. Open the media gallery for Test pattern, a project clip, a camera, or an NDI / Spout source. Mirror flips it. The groups under that are the sliders for the current look. Hover a slider to read it. Mute bypasses a group. The dice, Shuffle, shuffles that group. Double-click a slider to reset it.
                      
            
                      8. 
            
                    8. 
              
                      Tempo, loop, and timeline
                      
              
                      The tempo row is the clock for the shaders, the strobe, and the timeline. It starts at 120. Auto: Read Live listens for a few seconds, locks one tempo, then returns to manual. Tap/Phase (T) sets a tempo, or one tap on the beat lines the phase up. x2 and /2 double or halve it. Nudge moves it by 0.1. While Auto is listening, a Pioneer beat assigned to strobe still flashes, and it does not move the phase.
                      
              
                      Loop repeats the timeline. Bars sets its length, up to 2048. Drag the timeline’s top edge to make it taller. Scroll over it to zoom. Drop a scene or a clip on the ruler. Click the ruler to move the playhead. X-fade and the style menu set how one scene replaces another: Crossfade Alpha, Additive Bleed, or Wiping Glitch.
                      
            
                      9. 
            
                    9. 
              
                      Scenes
                      
              
                      Type a name and click Save Scene. The grid is three rows and scrolls to the right. Empty cells are waiting. Click a scene to launch it. Drag it to the timeline. Right-click it for the menu. C1, C2, and C3 in Composition are separate: they store the composition mix, not a scene.
                      
            
                      10. 
            
                    10. 
              
                      Hits and overlays
                      
              
                      The pads under Save Scene are holds: Strobe/Flash, Y2K Crash, Particle Scatter, Invert Colors, and Max Glitch. They last while the pad is down. Code and Screen turn those overlays on or off. Hold Code to open Code Overlay, or Screen to open Screensaver. Brand plays the logo chosen in the number menu. Hold Brand to open that logo in Brand Overlay.
                      
            
                      11. 
            
                    11. 
              
                      Composition
                      
              
                      This is the last pass, after A, B, and C are mixed. Master Speed and Output Brightness sit on the play row under the BPM. 1.00x is normal speed. 0 freezes motion. C1, C2, and C3 recall a stored mix. Click recalls, a long press stores, a right-click forgets.
                      
              
                      Shuffle randomizes Color & Texture, Distortion & Glitch, and Motion & Timing, and leaves Barrel alone. Those four groups start closed. The Lock icon keeps a group where it is, and Shuffle skips it. Strobe Source can be Manual, Beat Pulse, or Drop Pulse. Barrel bends the finished frame.
                      
            
                      12. 
            
                    12. 
              
                      Sound into the picture
                      
              
                      On a layer strip, pick Sub-Bass, Mid-Energy, High-Hats, LFO 1, or LFO 2, then set Depth and Gate. In the Inspector, each slider has its own audio row, including Punch, BPM Pulse, Song Energy, Drop Pulse, and Beat / Onset. Depth is how far the slider moves. Gate ignores quiet sound. A on a slider adds an LFO.
                      
            
                      13. 
            
                    13. 
              
                      Output and recording
                      
              
                      In Output, set the Preview shape. Master Output chooses a display. Pick an NDI, Syphon, or SPOUT size and click Send when another app should receive the picture. Advanced Output drags the corner pins onto a projector.
                      
              
                      In Recordings, set Scale to Fill or Fit, and Render scale to 0.5x, 0.75x, or 1x. The frame menu there is 16:9, 9:16, 1:1, or Native. Include audio puts sound in the file. Code, Screen, and the logos each have Include in Recording and Include in Output. ● REC is in the top bar. Click it again to stop.
                      
            
                      14. 
            
                    14. 
              
                      Diagnostics
                      
              
                      Open Helper / Diagnostics in the project column. It keeps updating. What's happening lists what is driving each control. What's messy flags clipping and stacked routes. Performance and Keep it readable flag load and hard-to-read setups. Click a warning to jump to that slider.
                      
            
                      15. 
            
                    15. 
              
                      Perform
                      
              
                      Perform is the hardware desk. APC Mini MK2 is the full map. XDJ-700 shows one to four decks. Pro DJ Link carries the beat, not the button notes. Buttons wait for a USB learn. Macro Knobs let one MIDI CC move several sliders.
                      
            
                      16. 
            
                    16. 
              
                      Keys
                      
              
                      Q, W, and E select a layer. 1–9 set that layer’s shader. Shift+1–8 launch a scene from the current set of eight. Space plays or pauses. T taps the tempo. L switches Live and Timeline. H toggles the code overlay. C cycles the overlay mode. P hides the panels. F is fullscreen. R starts or stops recording. Ctrl+Z undoes. Ctrl+Shift+Z or Ctrl+Y redoes.
                      
            
                      17. 
            
                    17. 
              
                      About
                      
              
                      Y2K VJ was custom-coded for the late future, to hold analog rawness and digital precision in the same hand. Rust and Tauri keep the instrument steady. WebGL draws the frame that exists only while it is playing.
                      
              
                      Glitch is a material, and the Y2K look is a tomorrow that already happened. The human brings the gesture. The machine brings the pulse. The vision is Cín’s. The app is an instrument for visual artists crossing the new ether.
