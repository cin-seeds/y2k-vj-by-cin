          MIDI

          MIDI Learn highlights the next slider, menu, or pad you click. APC Mini MK2 Default binds Channel 1 without Learn: pads 0–63, scene buttons 112–113, faders CC 48–50 and master CC 56, track buttons 64–67. Pad LEDs follow the live page.

          Macro Knobs

          One CC can move several sliders. Depth is how far it travels. Invert flips the direction.

          Output

          Keys: Q W E select layer · 1-9 layer shader · Shift+1-9 launch scene · Space timeline play/pause · T tap tempo · L live/timeline · H code HUD · C cycle overlay mode · P hide UI · F fullscreen · R record
          Each layer picks its own engine. 3D shaders: drag the preview to orbit, scroll to zoom. Double-click a slider to reset it.
